# Extension Icons

This directory should contain the extension icons:
- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

You can create simple placeholder icons or design custom ones.

## Quick Placeholder Creation

Use any image editor or online tool to create simple colored squares with "R20" text.

For now, the extension will work without icons, but Chrome will show a warning in the extensions page.
